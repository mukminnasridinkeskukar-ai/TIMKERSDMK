Petunjuk Penggunaan

Panduan lengkap menggunakan platform SIMBAKES

1. Mengakses Platform

Buka browser dan akses URL platform SIMBAKES. Tunggu landing page selesai (3 detik) untuk masuk ke dashboard utama.

2. Mengajukan Rekomendasi

Pilih menu Layanan → Ajukan Rekomendasi. Isi formulir dengan lengkap termasuk foto pasfoto, data pribadi, dan upload dokumen dalam format PDF.

3. Mengecek Status

Gunakan nomor register yang didapatkan setelah pengajuan untuk mengecek status di menu Cek Status Pengajuan.

4. Panel Admin

Admin dapat login dengan password admin123 untuk mengelola data pengajuan.
